[b]About[/b]
This thread contains my [b]Custom Kernel Builds[/b] for OPlus Devices. These are mainly intended for Testing, Development, and Performance.

[b]KernelSU Forks Included[/b]
[list]
[*][url=https://github.com/tiann/KernelSU]Official KernelSU (KSU)[/url]
[*][url=https://github.com/KernelSU-Next/KernelSU-Next]KernelSU Next (KSUN)[/url]

[/list]

[b]Source[/b]
[list]
[*]Based on the OPlus Kernel Tree [url=https://github.com/OnePlusOSS]OnePlusOSS[/url]
[*]Compiled with Clang Toolchain
[*]Custom patches applied
[/list]
[i]Note: Not all builds are guaranteed to be stable. Tested on Snapdragon 8 Elite / Oryon platforms.[/i]

[b]Features[/b]
[list]
[*][url=https://github.com/cctv18/susfs4oki]SUSFS4OKI (OKI)[/url] / SUSFS4KSU / [url=https://github.com/sidex15/susfs4ksu-module]SUSFS Module[/url]

[*]KPM Support
[*]ZRAM (LZ4 + ZSTD)
[*]IPSET
[*]BBR + ECN
[*]HMBIRD
[*]Unicode Bypass
[*]XUS Fix
[*]ADIOS I/O Scheduler
[*]More features will be added soon
[/list]
